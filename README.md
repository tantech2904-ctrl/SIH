# ULPF — Universal Log Pre-Processing Framework

**Team The Beetles · Smart India Hackathon 2026 · Problem Statement 26156**

ULPF is a vendor-agnostic cybersecurity log pre-processing and normalization layer.
It sits between heterogeneous security telemetry (firewalls, IDS/IPS, EDR, cloud,
authentication systems) and downstream consumers (SIEM, SOC, ML, data lakes, threat
intelligence correlation, incident response).

**From heterogeneous security logs to one common security language.**
