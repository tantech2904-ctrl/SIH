# Policy:
#   - Critical packages (fastapi, pydantic, sqlalchemy, celery):
#     bounded ranges. Stable across minor versions.

# __about__ module that passlib reads to log the version, which
# causes passlib to trap an AttributeError and fail every password
# verification. This pin is required.
# ============================================================
